# Easy GitHub Upload Guide

This ZIP contains the full Setka Cup prediction app with the correct folder structure.

## Best way to upload
1. Download this ZIP.
2. Extract/unzip it on your phone or computer.
3. Open your GitHub repo: https://github.com/goldstarpalms-svg/Sekta-cup
4. Use **Add file → Upload files**.
5. Upload the extracted folders/files exactly as they appear:
   - `.streamlit/`
   - `data/`
   - `docs/`
   - `models/`
   - `notebooks/`
   - `scripts/`
   - `src/`
   - `app.py`
   - `README.md`
   - `requirements.txt`
   - other root files
6. Commit changes.

Important: do not upload only the ZIP file to the repo unless you only want it stored as a download. The app needs the extracted files and folders.
